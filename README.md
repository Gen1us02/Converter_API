## Coverter API

Проект представляет собой API для работы с валютой и аутентификацией на основе JWT токена используя FastAPI

Возможности:
  - Обмен валюты из одной в другую
  - Получение списка доступных валют
  - Получение текущего курса по введенным валютам
  - Регистрация пользователя
  - Логин пользователя
  - Получение пользователя по username
  - Удаление пользователя
  - Изменение данных пользователя
  
Стек технологий:
  - FastAPI
  - Alembic
  - pytest
  - PostgreSQL
  - JWT
  - sqlalchemy
  - pydantic
  - httpx
  - Docker
  - Docker Compose
